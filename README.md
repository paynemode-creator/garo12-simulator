# GARO XII Simulator · 실기 외형 v1.3

이 패키지는 GARO XII 시뮬레이터 v1.1을 기반으로, 사용자가 제공한 **실제 파칭코 기기 사진**을 메인 UI로 적용한 v1.3입니다.

## 적용

1. ZIP 압축 해제.
2. `index.html`, `styles.css`, `app.js`, `README.md`, `assets` 폴더를 GitHub 저장소 `garo12-simulator` 최상위에 업로드하여 기존 파일 덮어쓰기.
3. 반드시 `assets/img/garo12-main-ui.jpg`가 저장소에 존재하는지 확인.
4. 기존 Pages 주소에서 `?v=13`을 붙여 새로고침 테스트.

## 기능

- 기존 추첨 엔진, 자동 회전, 상태/통계, 실험 기능 유지.
- 실제 기기 사진 위 액정 범위에 당첨 도안·배틀·LT 연출 겹쳐 표시.
- 실기 사진의 하단 LED 위치에 동적 출구슬 누적 표시.
- 우측 검 그립 클릭 시 PUSH 조작.
- v1.2 사운드 기본 ON 적용, 사용자의 브라우저 클릭 이후 음향 재생.
- 기존 로컬 통계 키 유지.

참고: 실제 LCD 영상이나 물리 역물의 정밀 재현은 별도 연출 영상/애니메이션이 필요합니다. 또한 업로드한 실기 이미지의 공개 배포 이용 권한은 사용자가 확인해야 합니다.
